# 使用指南

[返回项目首页](../README.md)

安装、完整快捷键、代理配置、数据口径及开发说明。展示名称为 **Ticktop**，仓库、Rust 包和命令名统一为 `ticktop`。

## 运行

可从 [v0.1.0 Release](https://github.com/Nyakooo/ticktop/releases/tag/v0.1.0) 下载 Linux/macOS 的可执行文件，或使用下面的一键安装命令。发布包无需 Rust、Python 或外部数据库。

以下源码运行方式仅供开发者使用：

```bash
cargo run --release
# 明确标注的离线演示；演示状态和缓存独立，避免污染真实行情
cargo run --release -- --demo
# 简约模式
cargo run --release -- --minimal
# 仅打印一份真实报价并退出，便于排查网络
cargo run --release -- --check
```

构建需要 Rust 1.88+ 和 C 编译器；发布的程序不需要 Rust、Python 或外部数据库。
Linux/macOS，建议 UTF-8 终端、支持中文和 Braille 的等宽字体。最低 46 列 × 16 行，
推荐 120 列 × 35 行；窗口不足 98 列时完整视图改为上下布局。
中文使用终端自身的输入法，应用接收已提交的字符。

## 一键安装

```bash
curl --proto '=https' --tlsv1.2 -fsSL \
  https://raw.githubusercontent.com/Nyakooo/ticktop/master/scripts/install.sh | bash
```

- 自动识别 Linux/macOS 和 x86_64/ARM64，校验 SHA-256 后原子替换程序。
- 默认安装到 `~/.local/bin/ticktop`，无需 `sudo`。
- 根据 `$SHELL` 识别用户 Shell，不根据执行安装脚本的 bash 误判。
- zsh / oh-my-zsh 写入 `${ZDOTDIR:-$HOME}/.zshrc`；bash 写入 `~/.bashrc`。
- 使用独立标记块，不重复追加 PATH，不覆盖现有 Shell 配置。
- 脚本无法修改父终端的环境；安装后按提示 `source ~/.zshrc` / `source ~/.bashrc`
  或打开新终端。bash 的 login shell 若没有加载 `.bashrc`，需自行在 login 配置中引用。

```bash
# 显式选择 shell / 固定版本
curl -fsSL https://raw.githubusercontent.com/Nyakooo/ticktop/master/scripts/install.sh \
  | bash -s -- --shell zsh --version v0.1.0

# 更新程序，保留全部个人配置
 ticktop update

# 指定存储目录（便携使用）
 ticktop --data-dir ./data
```

也可以从 Releases 下载对应压缩包及 `.sha256` 文件，校验、解压后 `./ticktop`。
指定二进制位置可设置 `TICKTOP_INSTALL_DIR`；`--no-path` 只安装、不修改 Shell 配置。
删除 `~/.local/bin/ticktop` 即可卸载程序；个人数据默认保留，可按下面路径自行清理。
Shell 配置中的 `# >>> ticktop >>>` 区块可以手动移除。

## 操作

支持鼠标：云图悬停或点击板块查看详情、滚轮或点击 `[ 上页 ][ 下页 ]` 翻页，点击行业/概念标签切换分类；底栏点击 `m` 切换完整/简约，点击 `h` 切换视图。终端需支持鼠标上报；按住 Shift 通常可恢复终端文字选择。首末页会给出提示。

| 按键 | 行为 |
| --- | --- |
| `m` | 完整 / 简约，保留当前分组、股票、周期和视图 |
| `h` | 自选行情 / 全市场板块云图 |
| `[` / `]` | 行情页切换自选分组 |
| `Tab` | 云图切换行业 / 概念分类 |
| `s` | 云图排序：涨幅优先 / 跌幅优先 / 规模优先（成分股数），自动记住 |
| `PgUp` / `PgDn`，`p` / `n` | 云图翻页（终端拦截翻页键时用 p/n）；`Home` / `End` 跳到首末板块 |
| `↑` / `↓` | 选股；长列表和热力图自动滚动 / 翻页 |
| `←` / `→` | 日内 / 1 周 / 1 月 |
| `j` / `k`，`Home` / `End` | 移动走势游标，查看对应价格 |
| `/` | 搜索；支持中文 / 代码 / 拼音 / 首字母 / 小幅拼写错误 |
| `Enter` | 搜索结果中预览股票；不会自动加入自选 |
| `a` | 搜索并添加到指定自选分组 |
| `Ctrl+a` | 搜索输入中将当前结果加入分组 |
| `d` | 从当前组移除股票，确认后执行；全部自选中移除会同时移出其他组 |
| `g` | 管理分组：`n` 新建、`r` 重命名、`d` 删除、`Enter` 切换 |
| `Space` | 暂停 / 恢复显示，后台请求继续；恢复时显示最新数据 |
| `,` | 网络和刷新设置，`Tab` 切字段，`Ctrl+u` 清空，`Enter` 保存立即生效 |
| `?` | 帮助、股票和分组编号对应关系 |
| `Esc` | 关闭弹层 / 搜索 |
| `q` / `Ctrl+c` | 退出（输入框里的 q 正常输入） |

简约股票列表显示带市场前缀的股票代码（如 `sz300750`），不显示公司名称；原稳定编号仍可在帮助中查看。`age(s)` 是**源报价**距现在的秒数，不是请求间隔；
`E01` 表示报价请求异常，`E02` 表示走势异常，`E03` 表示板块请求异常，保留最后有效缓存。

大盘云图独立于自选，展示新浪公开接口返回的**全部行业板块 / 全部概念板块**，
不是自选股，也不是只展示涨幅榜前几名。当前验证分别为 84 / 175 个，实际数量由来源决定。
完整模式恢复规整分行的加权色块，按当前排序从左到右、从上到下阅读。名称保持横排，长名称缩略，选中后底部显示全名。简约模式显示单色序号、板块名称和涨跌幅；长名称按列宽缩略，选中后底部显示完整名称。
默认按涨跌幅降序排序，缺失涨跌幅的板块放在末尾，同值按来源代码稳定排列。按 `s` 或点击分类旁的排序标签切换排序，完整和简约模式共用并记住设置。刷新后保留当前选中板块，主动切排序返回第一页。方向键选择板块，翻页可到达全部数据。切分类、切模式不会改变自选的分组、股票或走势周期。

红涨绿跌；完整模式以本页成分股数量为面积权重绘制分行色块，并非市值占比。简约模式使用单色名称与涨跌幅矩阵。概念板块成分股可能重叠。涨跌幅采用新浪给出的板块**平均涨跌幅**，
不是交易所或基金指数；分类之间可能重叠，不能将各板块成分数或涨跌幅相加。
来源不提供板块行情时间戳，所以仅标注“获取时间”，不会冒充源时间或保证实时。
后台默认 30 秒刷新，仅在打开云图时请求，复用代理、暂停、重试和本地缓存机制。
失败时不会用自选行情或演示数据替代。技术指标、海外股票与 Crypto 留待后续。
1 周 / 1 月走势是最近 5 / 22 个交易日的不复权日收盘价，不是分钟线。
分时横轴按交易分钟排列，压缩午间休市，横轴标签保留实际交易时间。

## 配置

首次启动可选择默认模式。按 `m` 切换完整 / 简约模式后立即保存，下次直接运行
`ticktop` 会恢复上次模式；更新或重新安装程序也不会清除这个设置。
自选、分组和选中股票同样保存在本地。

`--minimal` / `--full` 会显式指定并记住启动模式。如果希望恢复上次选择，启动命令
不要固定带 `--full` 或 `--minimal`。演示与真实行情各自记住模式；`--data-dir` 不同
则使用各自的设置，第一次创建状态时会采用 `config.toml` 里的默认模式。

```toml
# config.toml
# 模式切换会同时记录 state.json 和默认模式；已有状态优先恢复上次选择。
default_mode = "full"

[network]
proxy_mode = "system" # system / custom / direct
proxy_url = ""
timeout_secs = 10

[refresh]
quotes_secs = 5
chart_secs = 15
sectors_secs = 30
```

```bash
ticktop --proxy http://127.0.0.1:7890
ticktop --proxy socks5h://127.0.0.1:1080
ticktop --no-proxy
ticktop --interval 10s
```

命令行覆盖配置文件，配置文件覆盖默认值。命令行覆盖不会自行写入配置；在设置页保存
时会保存当前设置。`system` 采用 HTTP_PROXY / HTTPS_PROXY / ALL_PROXY / NO_PROXY
及对应小写环境变量；`direct` 忽略代理环境变量；`custom` 仅走指定代理，失败不直连。
`socks5h` 将域名解析也交给代理。支持代理认证；界面、错误信息不输出凭据，配置文件
通过权限为 0600 的临时文件原子写入。不要把包含密码的配置提交进仓库。

间隔为 2–3600 秒，超时为 1–120 秒；同一类请求不重叠，失败指数退避，通常上限
300 秒（已设置更长间隔时不缩短间隔）。全市场板块独立请求，刷新间隔可在设置页修改。

默认路径：

| 文件 | Linux | macOS |
| --- | --- | --- |
| 配置 | `$XDG_CONFIG_HOME/ticktop/config.toml`，默认 `~/.config/ticktop/config.toml` | `~/Library/Application Support/ticktop/config.toml` |
| 数据 | `$XDG_DATA_HOME/ticktop/`，默认 `~/.local/share/ticktop/` | `~/Library/Application Support/ticktop/` |

数据目录保存 `state.json`、SQLite 缓存。`--data-dir DIR` 将配置和数据都放入 DIR。
演示使用独立的 `demo-state.json` / `demo-cache.sqlite3`。
损坏的自选文件会报错，程序不会偷偷覆盖它；请先备份再修复。

## 免费数据与边界

- 报价：[腾讯公开行情](https://qt.gtimg.cn/q=sh600519)，GBK 数据转换为 UTF-8。
- 分时 / 日历史：腾讯公开走势图接口。
- 全市场板块：[新浪行业/概念数据](https://vip.stock.finance.sina.com.cn/q/view/newFLJK.php?param=industry)。
- 股票名单：[巨潮资讯公开名单](https://www.cninfo.com.cn/new/data/szse_stock.json)。
  内置一份名单以保证首次离线可搜索，后台按日更新并缓存。
- 这些是公开站点接口，**不是有服务保证的授权实时行情产品**。可能限流、变更或缺失，
  本程序仅面向个人查看；数据使用仍受提供方条款约束，不提供再分发保证。
- 休市、停牌、未上市和退市证券可能返回旧快照或无报价；显示源时间，不假装实时。
- 请求失败保留旧值并提示；真实模式不会回退到随机演示数据。
- 价格用万分之一元整数解析和存储，仅图表与涨跌幅计算转换浮点数。

### 筹码峰（本地估算）

完整模式在个股走势右侧显示筹码峰，使用独立价格轴；窗口较窄时显示数字摘要。简约模式只显示估算均价、90% 成本区间和日线获利比例。无需额外按键，切换股票自动加载。

数据来自东方财富免费公开日 K 线接口，取最近最多 240 个交易日的前复权价格及换手率，每 30 分钟更新，仅请求当前股票，云图打开时停止请求。遵循已有代理设置，失败保留缓存；暂停时冻结展示，恢复后应用最新结果。界面显示源数据日期，盘中最后一个日线条目可能尚未收盘。

计算采用 200 个价格档：每日旧筹码乘以 `(1 − 换手率)`，当日换手部分按最低至最高价的三角分布加入，三角峰位为 `(最高 + 最低 + 收盘) / 3`；换手率超过 100% 按全部换手处理。首日分布作为未知早期持仓的初始估计，界面中的“初始残留”表示该初始估计尚存权重。停牌、历史窗口长度及初始假设都会影响结果，与其他软件可能不同。

估算均价为价格档加权平均；90% 区间取 5% 和 95% 加权分位数；日线获利比例按最后一条日线收盘价计算，不随实时现价变化。图中红色表示成本不高于该日线收盘价，绿色表示更高，横条长度为该价位区间的估算权重。筹码峰不是实际股东持仓，也不是东方财富官方筹码分布结果。


### 走势图价格读数

左侧价格轴根据可用高度和波动幅度自动分配刻度，刻度以整分计算，保持等距且不重复。图上方的“末价”对应走势最后一个数据点及其时间，不一定等于实时行情报价。使用 `j/k` 查看历史位置时，显示该点的价格与时间，并用水平、垂直参考线定位。A 股价格显示到分，不通过增加无意义小数制造精度。
