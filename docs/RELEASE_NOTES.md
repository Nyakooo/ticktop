# Ticktop v0.5.6

- 手动排序统一为 Alt＋↑/↓，适用于 A 股自选、指数个人关注和分组管理。
- 美股新增 t 置顶／取消置顶和 Alt＋↑/↓ 排序；全部订阅与各分组独立保存，置顶区与普通区分别排序，完整和极简模式均有置顶标识。
- 美股按 a 或 / 打开模糊搜索列表，支持代码、中英文名称、拼音／首字母及模糊匹配，选中后回车添加到当前分组。
- 免费在线搜索补充更多美股股票，沿用代理设置，输入防抖并取消过期请求；断网保留本地结果，也可按代码添加。中文／拼音覆盖本地中文名称目录，在线主要提供英文名称与代码。
- 在线订阅的名称、置顶和顺序重启保留，旧配置自动采用新增字段的默认值。

已安装用户运行 `ticktop update`。各平台安装包及 SHA-256 校验文件见下方附件。
