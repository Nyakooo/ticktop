# Ticktop v0.5.1

- 新增独立市场页：F1 自选、F2 指数、F3 美股、F4 云图，保留 h 进入云图与返回前页。
- 全球指数总览整合13个内地、香港、日韩及美国指数，支持个人关注、搜索添加、取消关注、置顶、排序与别名，Enter 查看走势、Esc 返回总览。
- 美股支持代码或内置中文名称订阅、独立分组、盘前/盘中/盘后分钟走势及日/周/月 K。
- 夜盘仅展示可获取的报价及源时间，暂无历史分钟曲线；不同阶段的报价与曲线末价可能不同，公开行情不保证实时。
- F1–F3 简约模式使用紧凑列宽与选中背景，宽屏下数据仍集中靠左；页面、关注和设置自动保存。
- 修复两市成交额收盘比较被时效规则隐藏的问题，同日15:00完整比较在断网、重启后保留，次日报价不混用旧比较。

- 修复 A 股和海外 K 线影线偏离实体中心、半格覆盖导致实体与影线出现视觉断层的问题，统一绘制网格。

已安装用户运行 `ticktop update`。各平台安装包及 SHA-256 校验文件见下方附件。
